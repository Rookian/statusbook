          Google Maps place names

          To get place names from Google, you need your own Google Maps API key:

          1. Open the Google Cloud Console and sign in with your Google account.
          2. Create a project: project picker in the top bar → New project, e.g. "Statusbook".
          3. Set up billing when asked (Billing). Google requires a billing account even for the free amount.
          4. Turn on the Geocoding API: click Enable.
          5. APIs & Services → Credentials → Create credentials → API key, then copy the key.
          6. Recommended: edit the key → API restrictions → Restrict key → Geocoding API. You can also set a daily limit under the Geocoding API's Quotas.

          Cost: Google gives 10,000 free lookups per month (as of 2026). The tool looks up each spot only once and keeps the names.

          Identify animals

          Statusbook can ask an AI model what fish or other animal a photo or video frame shows. You need your own API key from one of these providers:

          1. Claude: console.anthropic.com → API keys
          2. Gemini: aistudio.google.com → Get API key
          3. OpenAI: platform.openai.com → API keys
